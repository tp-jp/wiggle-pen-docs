# wiggle-pen-docs

ぶるぶるペン（WigglePen / WigglePenAvatar）のドキュメント公開用リポジトリです。VitePress + GitHub Pagesで構成しています。

[ドキュメントサイト](https://tp-jp.github.io/wiggle-pen-docs/)

## ローカル確認

Node.js 24を使用します。本文は `docs/` 内のMarkdownで編集します。

```sh
npm ci
npm run docs:dev
```

ビルド・リンク確認は `npm run docs:build`、`npm run docs:check`。
