# 描画設定

Playモードを終了し、アバター直下の **WigglePen_Right** または **WigglePen_Left** を選択します。Inspectorの **Avatar Pen Drawing Settings** で設定します。左右は個別に調整できます。

## 描画開始までの時間

**描画開始待機時間（秒）** は、Pointを維持してから描画を始めるまでの時間です。標準は **0.3秒**、0にすると待機なしになります。

指の形が変わる途中で線が出る場合は、待機時間を長くしてください。描き始めるまでの時間を短くしたい場合は、値を小さくします。

## 線幅・振幅の範囲

| Inspector項目 | 初期値 |
| --- | --- |
| 線幅の最小値 (mm) | 3 |
| 線幅の最大値 (mm) | 16 |
| 振幅の最小値 (mm) | 0 |
| 振幅の最大値 (mm) | 20 |

Expressionメニューのラジアル操作で、**0%が最小値、100%が最大値**になります。線幅や振幅を一定にしたい場合は、それぞれの最小値と最大値を同じ値にします。

設定できる範囲は0〜1000 mmです。初期値から少しずつ変更してください。線幅が0だと線が見えないため、線が出ない場合はメニューのサイズと線幅の最小値を確認します。

::: tip 単位の違い
ここで設定する線幅・振幅は **mm**、指先オフセットは **m** です。例えば6 mmは0.006 mに相当します。
:::

## 虹色の速さ

**虹色の一周時間（秒）** は、ゲーミングモードで色が一周する時間です。短くすると速く、長くするとゆっくり変化します。設定範囲は **0.1〜120秒** です。

Prefabの初期値は **1秒** です。Inspectorの説明に「標準は6秒」と表示される場合がありますが、実際に使われるのは入力欄の値です。

## ペン先の明るさ {#tip-emission}

Drawing Settingsの **ペン先の発光強度** で、ペン先メッシュと短い軌跡の明るさをまとめて調整します。初期値は **0.5**、設定範囲は **0〜5** です。

右手用・左手用のPrefabで個別に設定できます。マテリアルを直接編集する必要はありません。

値を大きくするとペン先が明るくなります。0にすると発光はなくなりますが、ペン先自体は表示されます。**描いた線（Ink）の明るさには影響しません。**

## 変更を確認する

シーンを保存してから、Gesture ManagerのPlayモードに入り直します。ペン先の明るさはペンをONにして確認してください。短い軌跡は手を動かすと確認できます。

メニューで変更した色・サイズ・振幅・ゲーミングの設定は保存されるため、メニュー側の値も確認してください。
