# 描く・消す・色を変える

Expressionメニューの **WigglePen**（左手用は **WigglePen（左手）**）から操作します。

## 描く・止める

**ペン ON/OFF** をONにすると、描画待ちになります。対応する手でPointを維持すると、待機時間の後に描画が始まります。標準の待機時間は0.3秒です。

| 状態 | 新しい線 | 描いた線 |
| --- | --- | --- |
| ペンOFF | 描きません | 残ります |
| ペンON、Point以外 | 描きません | 残ります |
| ペンON、Pointを待機時間以上維持 | 手を動かすと描きます | 残ります |
| 全消去 | 対象のペンの線を消します | 消えます |

右手用は右手のPoint、左手用は左手のPointで描画します。Gesture Managerで確認する場合は、対象の手のGestureを **3（Point）** にしてください。

::: tip ペンをOFFにしても線は残ります
描画を止める操作と消す操作は別です。線を消したいときは、メニューの「全消去」を使ってください。
:::

## メニューの項目

| 項目 | 操作 |
| --- | --- |
| ペン ON/OFF | 描画を有効・無効にします |
| 色 | ラジアル操作でパレットの色を変更します |
| サイズ | 設定された範囲内で線幅を変更します |
| 振幅 | 設定された範囲内で揺れの大きさを変更します |
| ゲーミング | 虹色に変化するモードを切り替えます |
| 全消去 | そのペンで描いた線をまとめて消します |

## 色と太さについて

**色とサイズの変更は、すでに描いた線にも反映されます。** 線ごとに異なる色や太さを残すことはできません。

ゲーミングをONにすると、パレットの色に関係なく虹色に変化します。パレットの色に戻すには、ゲーミングをOFFにしてください。

## ペン先の表示

ペン先のマーカーと短い軌跡は、描いた線とは別の表示です。マーカーは色・ゲーミング・ペンON/OFFに連動します。

マーカーの短い軌跡は手を動かすと現れ、止めるとすぐ消えます。

## Indexコントローラー

ペンがONでPointをしている間は、対象の手の指がアニメーションで制御されます。ペンをOFFにするかPointをやめると、指のトラッキングに戻ります。指の形やペン先の位置が合わない場合は、[位置合わせ](/avatar/placement)と[困ったときは](/troubleshooting)を確認してください。
