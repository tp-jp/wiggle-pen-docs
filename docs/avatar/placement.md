# 指先の位置を合わせる

Prefabをアバター直下に配置すると、人差し指の先端が自動検出されます。ペン先が指に埋まったり、指から離れすぎたりする場合は、オフセットを調整します。

## 数値で調整する

1. Playモードを終了します。
2. Hierarchyで配置した **WigglePen_Right** または **WigglePen_Left** を選択します。
3. Inspectorの **Avatar Pen Auto Placement** を開きます。
4. **指先オフセット XYZ (m)** を調整します。
5. Sceneビューで位置を確認し、シーンを保存します。

単位はmです。1 mmだけ動かしたい場合は0.001を目安に少しずつ調整してください。XYZは人差し指の末端ボーンのローカル座標なので、指先方向がどの軸になるかはアバターによって異なります。

## Sceneビューで調整する

同じPrefabを選択すると、ペン先に移動ハンドルが表示されます。ハンドルをドラッグすると、XYZオフセットにも変更が反映されます。

- **Local**：指のボーンの軸に沿って動かします。
- **Global**：ワールドの軸に沿って動かします。

どちらで操作しても、保存されるXYZは末端ボーンのローカル座標です。ハンドルが見えない場合はSceneビューの **Gizmos** をONにしてください。

## Inspectorの確認項目

| 項目 | 内容 |
| --- | --- |
| Hand Anchor | 対象の手を指定するMA Bone Proxy。通常は変更不要 |
| Pen Tip | 自動配置するペン先。通常は変更不要 |
| 対象 | 検出された人差し指の末端ボーン |
| 位置の算出方法 | Endボーン・スキン頂点・関節間距離による推定のいずれか |
| 末端ボーン基準 | 算出されたローカル位置 |

## 調整後に保存する

変更は編集時に反映されます。ビルド時の再計算は行わないため、調整後はシーンを保存してください。Gesture Managerで確認中の場合は、一度Playモードを終了して調整し、再度Playモードに入ります。
