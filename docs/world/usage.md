# 描く・消す

QvPen拡張版の基本操作はQvPenと共通です。

## 描く

使いたい色のペンを持ち、Useボタンを押したまま動かします。Useボタンを離すと描画が止まり、描いた線が残ります。Useに割り当てられたボタンはコントローラーの設定によって異なります。

## 消す

消しゴムを持ち、Useボタンを押しながら消したい線に当てます。

QvPenのダブルクリック切り替えが有効な場合は、ペンをほぼ同じ位置に保ってUseボタンを素早く2回押すと、描画モードと消去モードを切り替えられます。

::: tip 持っているのに描けない場合
消去モードになっていないか確認してください。ダブルクリック切り替えが有効な場合は、もう一度切り替えると描画モードに戻せます。
:::

## 揺れ方を変える

線の揺れはUnityでインクマテリアルを編集して調整します。

[揺れを調整する](/world/settings)で、振幅・細かさ・更新頻度の違いを確認できます。
