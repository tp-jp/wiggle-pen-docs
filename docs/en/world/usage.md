# Drawing and erasing

The QvPen extension uses the same basic controls as QvPen.

## Draw

Pick up a pen in the color you want, then hold the Use button while moving it. Release Use to stop drawing. The lines you have drawn remain. The button assigned to Use depends on your controller settings.

## Erase

Pick up the eraser, hold Use, and touch the lines you want to erase.

If QvPen's double-click mode switching is enabled, hold the pen in roughly the same position and press Use twice quickly to switch between drawing and erasing.

::: tip Holding the pen but unable to draw?
Check whether it is in eraser mode. If double-click switching is enabled, switch modes again to return to drawing.
:::

## Change the wiggle

Adjust the wiggle by editing the ink materials in Unity.

See [Wiggle settings](/en/world/settings) for amplitude, detail, and update frequency.
