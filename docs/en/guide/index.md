# Choose a guide

WigglePen is a drawing asset that makes your lines wiggle. There are two versions: a QvPen extension for worlds and a version for avatars.

| | QvPen extension | Avatar version |
| --- | --- | --- |
| Asset name | WigglePen | WigglePenAvatar |
| Install on | A VRChat world | A VRChat avatar |
| Basic controls | Pick up a pen and hold Use to draw | Turn the pen on and make the Point gesture |
| Required tool | QvPen | Modular Avatar |
| First step | Place the prefab in your scene | Place the right or left hand prefab directly under the avatar root |
| Settings | Mainly the ink materials | Expressions menu and Unity Inspector |

## Setup

- For a world: [World setup](/en/world/)
- For your avatar: [Avatar setup](/en/avatar/)

Start with the default settings and check that you can draw, stop drawing, and erase.
