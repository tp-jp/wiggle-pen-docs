# Drawing, erasing, and colors

Open **WigglePen** in the Expressions menu, or **WigglePen（左手）** for the left hand. The Japanese menu labels below are followed by their English meanings.

## Draw and stop

Turn **ペン ON/OFF** (Pen ON/OFF) on to put the pen on standby. Hold the Point gesture with the corresponding hand to start drawing after a short delay. The default delay is 0.3 seconds.

| State | New lines | Existing lines |
| --- | --- | --- |
| Pen off | No drawing | Remain |
| Pen on, not pointing | No drawing | Remain |
| Pen on, Point held for the drawing delay | Draw as you move your hand | Remain |
| Clear all | Clears the selected pen's lines | Erased |

The right hand pen uses the right hand's Point gesture; the left hand pen uses the left hand's Point gesture. In Gesture Manager, set the corresponding hand's Gesture to **3 (Point)**.

::: tip Turning the pen off does not erase lines
Stopping and erasing are separate actions. To erase, use **全消去** (Clear all) in the menu.
:::

## Menu controls

| Menu label | Function |
| --- | --- |
| ペン ON/OFF (Pen ON/OFF) | Enables or disables drawing |
| 色 (Color) | Selects a palette color with a radial control |
| サイズ (Size) | Adjusts line width within the configured range |
| 振幅 (Amplitude) | Adjusts wiggle amplitude within the configured range |
| ゲーミング (Gaming) | Toggles rainbow color cycling |
| 全消去 (Clear all) | Erases all lines drawn with that pen |

## Color and width

**Changes to color and size also affect lines you have already drawn.** You cannot keep separate colors or widths for individual lines.

When Gaming is on, the colors cycle through the rainbow regardless of the palette setting. Turn Gaming off to return to the palette color.

## Pen tip display

The pen tip marker and its short trail are separate from the lines you draw. The marker follows the color, Gaming, and Pen ON/OFF settings.

The marker's short trail appears when you move your hand and disappears shortly after you stop.

## Index controllers

While the pen is on and you hold Point, animation controls the fingers of the corresponding hand. Turn the pen off or stop making Point to return to finger tracking. If the finger pose or pen tip position is wrong, see [Fingertip placement](/en/avatar/placement) and [Troubleshooting](/en/troubleshooting).
