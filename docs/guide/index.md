# ガイドの選び方

ぶるぶるペンは、描いた線がぶるぶると揺れるお絵描き用アセットです。ワールド用のQvPen拡張版と、アバター版があります。

| | QvPen拡張版 | アバター版 |
| --- | --- | --- |
| アセット名 | WigglePen | WigglePenAvatar |
| 導入先 | VRChatのワールド | VRChatのアバター |
| 基本操作 | ペンを持ち、Use操作で描く | ペンをONにし、人差し指を立てて描く |
| 必要なツール | QvPen | Modular Avatar |
| 最初の作業 | Prefabをシーンに配置 | 右手用・左手用Prefabをアバター直下に配置 |
| 調整する場所 | 主にインクのマテリアル | ExpressionメニューとUnityのInspector |

## 導入方法

- ワールドに置きたい方：[QvPen拡張版の導入](/world/)
- 自分のアバターで使いたい方：[アバター版の導入](/avatar/)

まずは初期設定のまま導入し、描画・停止・消去ができることを確認してください。
